# Historias de usuario y criterios de aceptación

## US-01 — Explorar productos
Como comprador, quiero ver el catálogo y abrir un producto para decidir si lo agrego al carrito.

**Aceptación:** el catálogo carga; la ficha abierta corresponde al producto seleccionado y muestra información consistente.

## US-02 — Gestionar el carrito
Como comprador, quiero agregar productos y consultar el total para revisar mi compra antes de confirmarla.

**Aceptación:** los productos agregados aparecen en el carrito y el total coincide con los importes visibles.

## US-03 — Completar la compra
Como comprador, quiero enviar datos de compra válidos para recibir una confirmación clara.

**Aceptación:** el formulario acepta datos válidos y la confirmación corresponde a una única acción de compra.

## US-04 — Corregir datos inválidos
Como comprador, quiero recibir mensajes útiles cuando falten datos o sean inválidos para poder corregirlos.

**Aceptación:** los datos requeridos se validan antes de confirmar la compra y los mensajes explican qué debe corregirse.

## US-05 — Recuperarse de estados límite
Como comprador, quiero que el sitio mantenga un estado coherente si el carrito está vacío o actualizo la página.

**Aceptación:** el sitio no muestra totales incorrectos y el comportamiento del carrito es consistente con el contrato esperado.

Los criterios son oráculos propuestos para verificar en el sitio de demostración; no representan resultados observados.
